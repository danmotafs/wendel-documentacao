# Documentação digital de publicações

Projeto por **Daniel Mota Ferreira — Inteligência Digital**.

Painel estático com busca, filtros, capturas de páginas, metadados e downloads individuais ou completos.

## Escopo

- 17 links fornecidos conferidos; 22 registros consolidados.
- Datas indisponíveis sinalizadas, sem inferências.
- Capturas com imagens carregadas quando o conteúdo estava acessível.
- SHA-256 verifica integridade dos arquivos, não autentica publicação ou data.
- Nenhum pedido ao Google foi protocolado na etapa de documentação.

## Publicação

Importe o repositório na Vercel. A configuração utiliza `public` como saída estática, sem instalação ou build. Os arquivos de evidências possuem nomes únicos para preservar sua identificação.

## Uso responsável

Os títulos reproduzem alegações das fontes identificadas, sem validar seu conteúdo. O inventário não representa levantamento exaustivo da internet. O painel orienta a organização dos documentos para avaliação jurídica por URL.

O processo judicial, documentos pessoais e a proposta comercial não integram este repositório.
